# Image Viewer Module

View TIFF image stacks with gallery and thumbnail modes. Browse individual slices, zoom, pan, and compare several stacks side by side.

The Image Viewer module provides a comprehensive interface for viewing TIFF image stacks commonly used in biomedical imaging.

## Key Features

- Gallery Mode: View individual slices at full size with zoom and pan controls

- Thumbnail Mode: See an overview grid of all slices for quick navigation

- Comparison Mode: View two to four stacks side by side with a shared slice slider, zoom, and pan

- Zoom & Pan: Use the mouse wheel to zoom and drag to pan

- Slice Navigation: Use the slider, the Previous/Next buttons, or the left/right arrow keys

- Integration: View results from segmentation and denoising modules directly

## Supported File Formats

The viewer supports multi-page TIFF files (.tif, .tiff), which are the standard format for microscopy image stacks. Both 8-bit and 16-bit images are supported, with automatic contrast adjustment for optimal viewing.

## Workflow

1. Select Image: Choose a TIFF stack from your workspace or recent results, and optionally add more stacks to compare

2. View Image: Browse through slices using gallery or thumbnail mode
