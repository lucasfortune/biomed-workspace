## 💡 Session Log Best Practices

### When to Create a Session Log

Create a new session log when:
- Starting work on a new feature
- Beginning a bug fix investigation
- Conducting a refactoring effort
- Completing a development phase

### Session Log Complexity Levels

Based on user preference, session logs vary by complexity:

**Simple Tasks:**
- Brief summary
- Files changed
- Outcome

**Medium Tasks:**
- Goals and summary
- Detailed task log
- Code changes

**Architectural Changes:**
- Full template
- Lessons learned
- Design decisions
- Trade-offs documented

### Naming Convention

Format: `YYYY-MM-DD_brief_description.md`

Examples:
- `2025-11-26_overlay_debug.md`
- `2025-11-26_cleanup.md`
- `2025-11-20_phase1_completion.md`
